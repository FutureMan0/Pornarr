# Contributing to Pornarr

Thank you for helping improve Pornarr. Before opening an issue, search existing
issues and use the supplied template. Please report security vulnerabilities
privately as described in [the security policy](.github/SECURITY.md).

For code changes, create a focused branch, keep the change covered by tests,
and run the relevant checks before opening a pull request. Pull requests must
describe the user-visible result and any operational impact.

Do not include real credentials, private media paths, or copyrighted media in
issues, commits, tests, screenshots, or fixtures.
