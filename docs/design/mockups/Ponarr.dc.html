Pornarr · UI mockups
Self-hosted video library — admin & guest
Two roles on one server. Admin owns scanning, matching, tags, queue and access; Guest — friends on the house network — gets only the viewing frontend: browse, search, collections, play. Ratings, comments and related titles run across both roles; the feed recommends from watch behaviour and what friends send you; the quality picker sits in the player. Artwork is hidden by default — the Art hidden control in any header reveals every tile on the board at once.
