# 0019 — Nine phases, ten milestones

Status: accepted (2026-08-07)

## Context
The plan defined nine development phases. They needed mapping onto releases.

## Decision
One milestone and one minor release per phase, with playback and OIDC split out as their own milestones. v1.0 coincides with the final hardening phase and with the repository going public.

## Consequences
After every milestone there is a running, tagged state, so work can stop at any point without leaving something half-built.
