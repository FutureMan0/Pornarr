# 0012 — MIT

Status: accepted (2026-08-07)

## Context
Stash uses AGPL-3.0, the *arr applications use GPL-3.0, Jellyseerr uses MIT. Relicensing later requires the agreement of every contributor.

## Decision
MIT, copyright held by "Pornarr Contributors".

## Consequences
Maximum reuse and the simplest possible contribution story. A closed-source commercial fork is permitted; that trade-off was made knowingly.
