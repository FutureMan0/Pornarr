# 0026 — English everywhere except team conversation

Status: accepted (2026-08-07)

## Context
The repository becomes public at v1.0. Anything written in German until then would be visible and would realistically never be translated.

## Decision
Code, comments, commits, pull requests, issues, labels, documentation, changelog and API error codes are English. Interface strings go through i18n from v0.1 with English as source and German as the first translation. Only conversation between the developers is German.

## Consequences
No retroactive translation effort at the point of publication.
