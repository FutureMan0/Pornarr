## SSRF review

Only administrator configuration can select outbound integration destinations.
Indexer base URLs and download-client hosts intentionally support private LAN
services, so a blanket private-address block would break the supported
self-hosted deployment model. No unprivileged request path can configure or
test those destinations. No metadata-provider HTTP client is implemented yet.

OIDC discovery is different: it accepts an arbitrary issuer and follows its
network response without a target policy. It is administrator-triggered, not
an unauthenticated SSRF, but it remains an uncontrolled server-side request.
It is tracked in **#231**. The issue requires HTTPS URL validation, DNS/IP
target restrictions on every connection, redirect controls, an explicit local
IdP opt-in, and executable tests.
