## SSRF review

Only administrators can configure self-hosted indexer and download-client
destinations, which deliberately may be private LAN services. OIDC discovery
is stricter: it accepts credential-free HTTPS issuers only, resolves every
connection immediately before use, rejects unsafe network targets, disables
redirect following, and offers a tested explicit private-IdP opt-in. The
regressions cover unsafe URLs, IP literals, DNS answers, redirects, public
issuers and the opt-in in `tests/api/test_oidc.py`.
